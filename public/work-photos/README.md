# 📸 Work Photos — Upload Here

This folder is a **staging area** for your real job-site photos.

## How to upload (GitHub web — easiest)

1. Open this folder on GitHub: `public/work-photos/`
2. Click **Add file → Upload files**
3. Drag & drop all your photos (you can select 50+ at once)
4. Commit directly to branch: `arena/01a0154a-klrenovator`
5. Tell the agent "photos uploaded" — it will pull, view each photo,
   rename to SEO-friendly names, convert to `.webp`, and add them to the
   website gallery.

## Rules

- ✅ Upload **original real photos** (JPG/PNG/HEIC are fine)
- ✅ Any photo count is fine (50+ OK)
- ⚠️ Keep total upload under ~500 MB — if a photo is bigger than 8 MB,
  resize it to max 2000px wide first (phone photos are usually fine)
- ❌ Do NOT rename photos yourself before uploading — the weird camera
  names (IMG_1234.jpg, 20250102_123456.jpg, etc.) are exactly what we
  want to fix
- ❌ Do NOT delete or edit other files in the repo

## What happens next (automatic)

1. Every photo is viewed and identified (brand, job type, area)
2. Files renamed to the repo's SEO pattern, e.g.
   `daikin-aircond-new-installation-klang-98.webp`
3. Converted + compressed to `.webp` for fast website loading
4. Added to the gallery (`config/gallery-items.ts`) with SEO alt text
5. Staging folder cleaned up afterwards
